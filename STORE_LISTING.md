# Chrome Web Store listing

## Name

Framer 中文补丁 — Framer Chinese UI Patch

## Short description

为 Framer 编辑器提供本地、可开关的简体中文界面补丁。

## Detailed description

Framer 中文补丁帮助设计师用中文理解 Framer 网页编辑器的工具栏、图层、右侧属性面板、交互菜单和动态三级选项。

特点：

- 本地词典翻译，无需 API Key
- 不上传 Framer 页面内容
- 支持动态菜单和常见 Shadow DOM 内容
- 支持自定义词典、编辑、删除、导入和导出
- 支持显示原文 / 显示中文切换
- 支持调试模式和漏翻术语反馈

## English description

Framer Chinese UI Patch is a local, toggleable Simplified Chinese localization helper for the Framer web editor.

It translates common toolbar labels, layers, right-side properties, interaction menus, and dynamically loaded options without sending page content to a translation service.

Features include a local glossary, custom term management, JSON import/export, original/translated view switching, debug highlighting for untranslated UI text, and a prefilled feedback flow.

## Privacy

See [PRIVACY.md](PRIVACY.md). No page content or translation data is sent to a remote translation API.
