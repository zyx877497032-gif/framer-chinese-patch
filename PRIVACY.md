# Privacy Policy

**Framer 中文补丁** does not collect, sell, or transmit personal data.

- Translation is performed locally in the browser with a bundled dictionary.
- Page text, Framer project content, and custom terms are not sent to a remote translation service.
- Settings and custom terms are stored using Chrome extension storage and remain associated with the user's browser profile.
- The optional feedback action opens a pre-filled GitHub Issue in a new tab. The user reviews and submits it manually; the extension does not automatically transmit feedback or store a GitHub token.
- The extension is an independent community project and is not affiliated with Framer, Inc.

For questions, use the issue tracker in the project repository.
