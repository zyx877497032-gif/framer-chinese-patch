# Framer 中文补丁（Chrome 扩展）

为 Framer 网页编辑器提供简体中文 UI 补丁。当前版本：`v0.4.1`。

## 安装

1. 打开 Chrome 的 `chrome://extensions`。
2. 开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本目录 `framer-chinese-patch`。
4. 打开或刷新 Framer 编辑器页面。

## 说明

- 使用 Manifest V3，无远程脚本，无数据收集。
- 默认开启，可通过扩展弹窗关闭。
- 目前覆盖工具栏、图层、右侧属性面板、交互面板、动态菜单和常见三级选项。
- 使用本地人工维护词典，不调用翻译 API，不上传页面内容。
- 采用 UI 白名单扫描，尽量避免翻译用户的图层名称、画布文本、CMS 内容、代码和输入框。
- 支持 Framer 动态加载的菜单，并使用防抖扫描减少界面卡顿。
- 支持常见 Shadow DOM 内容和 `aria-label`、`title` 等无障碍属性。
- 补充变量、布局、填充、描边、动画、交互和覆盖设置等右侧面板术语。
- 弹窗提供术语反馈表单，提交后生成预填好的 GitHub Issue；不需要在插件中保存 GitHub Token。
- 关闭插件后可以恢复当前页面的英文界面。
- Framer 更新界面后，可能需要补充 `content.js` 中的词典。

## 更新后测试

1. 在 `chrome://extensions` 找到「Framer 中文补丁」。
2. 点击「重新加载」。
3. 刷新 Framer 编辑器页面。
4. 打开右侧属性面板、交互菜单和三级弹出菜单，检查动态内容是否翻译。
5. 关闭弹窗里的中文界面开关，确认英文可以恢复。
